#ASP.NET MVC Portfolyo Projesi

Bu proje, Acunmedya Akademi kapsamında staj programı altında ödev olarak hazırlanmıştır

#📌 Kullanılan Teknolojiler

🔹 ASP.NET MVC – Model-View-Controller mimarisi

🔹 Entity Framework (DB First) – ORM tabanlı veritabanı yönetimi!

🔹 SQL Server – Güçlü ve ölçeklenebilir veritabanı yönetimi

🔹 HTML, CSS, JavaScript – Etkileşimli kullanıcı deneyimi

#📌 Öne Çıkan Özellikler

 ✅ CRUD İşlemleri (Ekle, Güncelle, Sil, Listele)
 
 ✅ Admin Paneli – İçeriklerin kolayca yönetilebildiği özel arayüz
 
 ✅ Dinamik Veri Yapısı – Projeler, yetenekler, eğitim ve özgeçmiş gibi bilgiler yönetilebilir
 
 ✅ İletişim Formu – Kullanıcı mesajlarını panelden görüntüleme
 
 ✅ Responsive Tasarım – Her cihazda sorunsuz çalışan modern arayüz
